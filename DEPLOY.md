# Civil Radar - Deployment Guide\n\nChoose your platform and follow the steps below to get Civil Radar live in minutes.\n\n---\n\n## Option 1: Railway (Recommended - Easiest)\n\n### Setup (3 minutes)\n\n1. Go to https://railway.app\n2. Sign in with GitHub\n3. Click \"New Project\" → \"Deploy from GitHub repo\"\n4. Select `Coryline/Civil-Radar`\n5. Railway auto-detects the Dockerfile and deploys\n6. Wait 2-3 minutes for the build\n7. Click \"Generate Domain\" to get your public URL\n\n**Your live app will be at:**\n```\nhttps://<railway-auto-generated-domain>.up.railway.app/static/index.html\n```\n\n**Optional:** Add environment variables in Railway dashboard for live feeds:\n- MASTODON_BEARER=your_token\n- REDDIT_CLIENT_ID=your_id\n- REDDIT_CLIENT_SECRET=your_secret\n\n---\n\n## Option 2: Heroku (Free - Requires Credit Card)\n\n### Setup (2 minutes)\n\n1. Install Heroku CLI: `brew install heroku` (or download)\n2. Login: `heroku login`\n3. Create app: `heroku create civil-radar-<your-name>`\n4. Deploy: `git push heroku main`\n5. Open: `heroku open`\n\n**Your live app will be at:**\n```\nhttps://civil-radar-<your-name>.herokuapp.com/static/index.html\n```\n\n---\n\n## Option 3: Render (Free - No Credit Card)\n\n### Setup (4 minutes)\n\n1. Go to https://render.com\n2. Sign in with GitHub\n3. Click \"New +\" → \"Web Service\"\n4. Connect GitHub and select `Coryline/Civil-Radar`\n5. Fill in:\n   - Name: `civil-radar`\n   - Environment: Python 3\n   - Build command: `pip install -r requirements.txt`\n   - Start command: `uvicorn app.main:app --host 0.0.0.0 --port 8000`\n6. Click \"Create Web Service\"\n7. Wait 3-5 minutes for build and deployment\n\n**Your live app will be at:**\n```\nhttps://civil-radar.onrender.com/static/index.html\n```\n\n---\n\n## Option 4: Fly.io (Free Tier - Global)\n\n### Setup (5 minutes)\n\n1. Install Fly CLI: https://fly.io/docs/getting-started/installing-flyctl/\n2. Login: `flyctl auth login`\n3. In the repo directory, run: `flyctl launch`\n4. Choose app name: `civil-radar`\n5. Choose region: (pick closest to you)\n6. Accept defaults\n7. Deploy: `flyctl deploy`\n\n**Your live app will be at:**\n```\nhttps://civil-radar.fly.dev/static/index.html\n```\n\n---\n\n## Option 5: Replit (Instant - No Setup)\n\n### Setup (1 minute)\n\n1. Go to https://replit.com\n2. Click \"+ Create\" → \"Import from GitHub\"\n3. Paste: `https://github.com/Coryline/Civil-Radar`\n4. Click \"Import\"\n5. Replit auto-runs the app\n6. Click \"Share\" → get your live link\n\n**Your live app will be at:**\n```\nhttps://civil-radar--<username>.repl.co/static/index.html\n```\n\n---\n\n## Option 6: Docker Hub + Any VPS\n\nIf you have your own server (DigitalOcean, AWS, Linode, etc.):\n\n```bash\n# Build and push to Docker Hub\ndocker build -t <dockerhub-username>/civil-radar:latest .\ndocker push <dockerhub-username>/civil-radar:latest\n\n# On your server\ndocker run -p 8000:8000 <dockerhub-username>/civil-radar:latest\n```\n\n**Your live app will be at:**\n```\nhttps://<your-server-ip>:8000/static/index.html\n```\n\n---\n\n## Once Deployed\n\nAfter you get your live URL:\n\n1. Open: `https://<your-domain>/static/index.html`\n2. See the map with demo protest events\n3. Search locations with the input box\n4. Click markers for details\n5. API docs at: `https://<your-domain>/docs`\n\n---\n\n## Enable Live Feeds (Optional)\n\nTo enable real Mastodon, Reddit, or Telegram ingestion:\n\n1. Get API credentials from each platform\n2. Add environment variables on your platform's dashboard\n3. Restart the app\n4. Watch live events appear on the map\n\n---\n\n## Troubleshooting\n\n**App won't start?**\n- Check logs on your platform dashboard\n- Ensure Python 3.12+ is installed\n- Verify requirements.txt is in repo root\n\n**Map not showing?**\n- Check browser console for errors (F12)\n- Ensure /static/index.html is being served\n- Try opening /api/protests to see JSON data\n\n**No protest events?**\n- Demo data loads on first startup\n- Check database connection\n- Try POSTing a test event to /api/protests\n\n---\n\n**Questions?** Open an issue on GitHub.\n"
